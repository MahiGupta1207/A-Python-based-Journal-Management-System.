# Journal Management System 

A simple Python-based Journal Management System that allows users to maintain their daily journal entries.

## Features

- **Add Entry:** Create a new journal entry with title, mood, location, tags, and text.
- **View Entries:** Display all saved journal entries.
- **Search Entry:** Search journal entries using keywords.
- **Edit Entry:** Modify previously saved entries.
- **Delete Entry:** Remove unwanted journal entries.
- **Date & Time:** Automatically records the date and time of each entry.

## Technologies Used

- Python
- File Handling
- Functions
- Lists
- Exception Handling
- Datetime Module

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
python journal_manager.py
```
